Source Code

MDI is a living, open-source project — the repository may include improvements made after the manuscript was finalized. The book emphasizes architecture and public APIs; where implementation details matter (thread ownership, rendering order, lifecycle behavior), the text discusses them explicitly. Reading the source is encouraged, not discouraged:

  • github.com/heddle/mdi-3D
  • github.com/heddle/mdi_radar
  • github.com/heddle/mdi-ml-classifier
