Try It

git clone https://github.com/heddle/mdi.git
cd mdi
mvn install
mvn exec:java -Dexec.mainClass=edu.cnu.mdi.app.DemoApp

DemoApp opens a virtual desktop preloaded with a drawing view, a map view, a plot view, and several simulation/optimization demos (network decluttering, traveling-salesperson simulated annealing, image evolution via a genetic algorithm, and a geometry-slice view) — a useful first stop before reading the chapters in detail.
