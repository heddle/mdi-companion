mdi_radar

A standalone radar/map demonstration application, built on the mapping chapter’s MapView2D architecture.

github.com/heddle/mdi_radar

What It Demonstrates

mdi_radar extends the MDI map view with radar-specific tools and content, showing how a domain-specific application can sit on top of the general mapping layer without modifying it:

  • Radar preset tools and a dedicated button palette (RadarButton, RadarButtonPalette)
  • Map-native radar items (RadarItem) with basing and parameter models (RadarBasing, RadarParameters)
  • ETOPO5 terrain/bathymetry shading, loaded from MDI’s bundled classpath resources
  • Terrain-aware line-of-sight visualization, using great-circle geodesy (Geodesy) and a Plate Carrée projection

Try It

git clone https://github.com/heddle/mdi_radar.git
cd mdi_radar
mvn install
mvn exec:java -Dexec.mainClass=edu.cnu.mdi.radar.app.RadarApp

Dependency

mdi_radar depends on the core mdi framework, currently the released 1.2.2.
